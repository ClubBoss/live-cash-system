## Purpose

Prevent premature admission, uncontrolled architecture churn and invented precision after completion of all catalogued source families.

Source ingestion is complete. Remaining work is evidence production:

- independent anchors;
- exact boundaries;
- material visual verification;
- original drill answer keys;
- learner diagnostics;
- target-game field calibration;
- final compression and admission.

## Final-rule optimisation rule

The final rule count is not preset.

Use:

`MINIMUM COMPLEXITY SUBJECT TO NO MATERIAL EV LOSS`

The 16 provisional synthesis slots are non-binding containers.

A merge requires evidence that one cue retrieves both mechanisms safely. A split requires evidence that combined retrieval causes material scope errors, latency or EV loss.

## Priority rule

Work order follows:

```text
spot frequency
x average error cost
x current error probability
x transfer value
x learnability per unit time
x evidence confidence
```

Personal discomfort and source sequence are inputs, not automatic priority.

## Change levels

### Level 0 - Evidence only

New support, insufficiency, visual detail or field observation. No learner-state impact.

### Level 1 - Explanation or boundary

Same mechanism; clearer cue, exception or context split. Preserve existing mastery and test only the added branch.

### Level 2 - Drill or anchor activation

A stable original answer key or independently validated anchor becomes available. Add changed variants; do not reset unrelated progress.

### Level 3 - Candidate revision

The mechanism meaning, scope or default changes materially. Make affected mastery provisional and create a repair path.

### Level 4 - Architecture change

Module, candidate or state representation is inadequate. Requires explicit defect report and migration plan.

## Source completion boundary

No active authority may use `wait for Carrot`, `Grade 3 pending` or a generic future-course dependency as a blocker.

Unknown supplements may be ingested if supplied, but their possible existence does not block current evidence work.

## No-admission rule

Cross-source agreement is not enough.

Admission requires:

- observable trigger;
- scoped default and exception;
- original product wording;
- stable direct drill;
- acceptable misuse risk;
- anchor or boundary support where required;
- field evidence where exploit magnitude is claimed;
- no unresolved same-assumption contradiction.
