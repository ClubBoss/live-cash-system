No relevant branch observations.

Action: use baseline and observe.

### Grade 1 — Suggestive

One or two compatible actions without reliable range information.

Action: choose robust candidates only; no extreme deviation.

### Grade 2 — Branch evidence

Repeated relevant actions plus showdowns or response patterns consistent with the hypothesis.

Action: moderate branch-specific adjustment.

### Grade 3 — Strong branch evidence

Multiple relevant nodes, hand-class evidence and no active falsifier.

Action: larger exploit permitted; continue monitoring adaptation.

# `CI-PH-001` — Small flop range-bet overfold / under-three-bet

Trigger:

- heads-up SRP;
- small plausibly range-wide c-bet;
- defender has legitimate raise support;
- effective depth permits a non-all-in raise.

Exploit if evidenced:

- expand small check-raises;
- add vulnerable thin-value/protection hands;
- preserve strong low-urgency calls;
- use backdoors that unblock folds.

Falsifiers:

- selective c-bet range;
- wide calls with weak pairs/ace-high;
- meaningful flop three-bets;
- tight origin range;
- adaptation.

# `CI-PH-002` — Bet-check-bet river overbluff

Trigger:

- wide or high-frequency flop c-bet;
- turn check removes part of strong value;
- river bet after Hero checks;
- large missed-hand supply remains.

Exploit if evidenced:

- bluff-catch wider with hands that beat the actual missed region;
- reduce blocker obsession when range-level overbluff is large.

Falsifiers:

- tight origin range;
- turn check traps substantial value;
- river heavily improves value;
- selective small river value range;
- opponent shows disciplined give-ups.

# `CI-PH-003` — 3-bet-pot triple-barrel overfold

Trigger:

- wide late-position 3-bet configuration;
- turn size leaves marginal bluff-catchers;
- river does not strongly repair defender;
- opponent has shown excessive river folding.

Exploit if evidenced:

- follow through with robust missed draws and low-showdown candidates;
- preserve credible value and runout discipline.

Falsifiers:

- defender calls marginal one-pair hands appropriately;
- river improves defender's concentrated range;
- early-position/tight configuration;
- opponent adapts or identifies Hero.

# `CI-PH-004` — Unfiltered-range aggression overbluff

Trigger:

- wide starting range reaches turn/river with little voluntary filtering;
- opponent bets after Hero showed weakness;
- normal or small size;
- runout leaves broad air supply.

Exploit if evidenced:

- continue wider with real bluff-catchers;
- treat blockers as refinement after ancestry.

Falsifiers:

- tight starting range;
- highly value-completing board;
- large polar sizing;
- evidence that the player checks air and bets selectively.

# `CI-PH-005` — Origin-range width predicts over/underbluff

Trigger:

- compare otherwise similar lines across wide and tight preflop configurations.

Exploit if evidenced:

- defend more against wide air-rich origins;
- fold more against tight air-poor origins.

Falsifiers:

- later filtering reverses the range shape;
- board removes natural air;
- tight range contains a clear bluff family;
- wide range reaches node through repeated strong filters.

This is a prior, not a standalone action rule.

# `CI-PH-006` — Turn probe too wide and merged

Trigger:

- preflop raiser checks back flop;
- OOP caller probes turn;
- probe contains weak pairs, single-card draws or random air;
- branch appears unable to defend raises.

Exploit if evidenced:

- retain strong check-backs;
- call more showdown value;
- raise more value and selected semi-bluffs;
- pressure later streets when range remains capped.

Falsifiers:

- probe range is polar and selective;
- opponent checks weak middle range;
- probe/three-bet or probe/call defence is strong;
- turn strongly favours OOP value.

# `CI-PH-007` — Flop float over-stab / overfold

Trigger:

- OOP preflop raiser checks a protected flop range;
- IP caller stabs frequently;
- stab range includes excess air or weak showdown;
- opponent folds too much to check-raises.

Exploit if evidenced:

- check-raise low-showdown and semi-bluff candidates;
- call more with bluff-catchers;
- preserve strong checks.

Falsifiers:

- IP stabs selectively;
- IP defends raises with calls and bluff reraises;
- OOP checking range is actually weak/capped;
- turn cards repair IP after a raise.

# `CI-PH-008` — Small river probe overfold

Trigger:

- earlier bet-check branch weakens IP range;
- river gives OOP adequate value/range support;
- small probe gives a price requiring wide calls;
- opponent folds high cards and weak pairs inelastically.

Exploit if evidenced:

- use thin value and low-cost bluffs;
- prefer smaller size when the same folds persist;
- prepare for occasional raise response.

Falsifiers:

- IP check-back range is protected;
- opponent calls price-correct bluff-catchers;
- opponent raises enough;
- OOP lacks value for a merged small range.

# `CI-PH-009` — 3-bet-pot click-back overfold / under-three-bet

Trigger:

- Hero is IP caller in 3-bet pot;
- OOP 3-bettor c-bets too widely;
- small flop raise creates demanding defence;
- OOP folds too much and rarely bluff three-bets.

Exploit if evidenced:

- expand bluffs, thin value and denial raises;
- preserve some strong calls;
- fold more of the expanded region to value-heavy three-bets.

Falsifiers:

- selective c-bet range;
- wide call defence;
- meaningful bluff three-bets;
- low SPR or board gives OOP concentrated nuts;
- opponent adapts.

# `CI-PH-010` — Filtered-node underbluff

Trigger:

- tight or moderate origin range;
- multiple voluntary filters before river aggression;
- few natural bluff families survive;
- value reaches node easily;
- opponent lacks evidence of creative conversions.

Exploit if evidenced:

- fold bluff-catchers more than equilibrium;
- ignore visually attractive blockers until credible bluffs are identified;
- remove speculative continues earlier against value-heavy branches.

Falsifiers:

- wide air-rich origin;
- unfiltered prior path;
- opponent shows converted showdown bluffs;
- missed draws naturally reach the node;
- sizing or line excludes much of value.
