# General Live Cash — Table Cues Quick Reference v0.1

Status: `PROVISIONAL / TABLE-FACING`

Purpose: compress the current reasoning system into short questions that can be recalled during play.

## Before preflop action

1. **Effective depth**  
   `How deep is this exact confrontation?`

2. **Straddle translation**  
   `How many straddles deep, and what SPR will I create?`

3. **Exploit expansion**  
   `Is this a baseline candidate or an invention?`

4. **Range source**  
   `Which range arrived from this position and action?`

## On the flop

5. **Size shape**  
   `How much weak range exists behind this size?`

6. **Deep OOP discipline**  
   `Does my range need this raise, or do I just hate future streets?`

7. **Multiway structure**  
   `Who can still wake up behind me?`

8. **Opponent model**  
   `What exact hand class is added or missing?`

## On the turn

9. **Range filter**  
   `What did the flop action remove?`

10. **Card ownership**  
    `Did this card preserve my advantage or repair theirs?`

11. **Barrel job**  
    `Which rivers does this hand cover?`

12. **Branch split**  
    `Which strong hands were already spent?`

## On the river

13. **Value count**  
    `What value is realistically left after this exact size?`

14. **Bluff ancestry**  
    `Which bluffs entered preflop and survived every street?`

15. **Blocker audit**  
    `What value, bluffs and folds does my card actually remove?`

16. **Evidence calibration**  
    `Is this a proven branch read or a story from one hand?`

# Emergency five-question sequence

When time is short:

1. Effective stack?
2. What range is behind the action?
3. What did prior action remove?
4. What is my hand's job?
5. What evidence supports the exploit?

# Domain algorithms

## SRP

`SIZE SHAPE → RANGE FILTER → CARD OWNERSHIP → COMBO JOB → RIVER PLAN`

## 3-bet pot

`PREFLOP SHAPE → BLUFF SUPPLY → FLOP BRANCH → COMPENSATION → FUTURE BLUFFS`

## Multiway

`NUT OWNER → SANDWICH → SHARED DEFENCE → EXPECTED AGGRESSION → BACKUP EQUITY`

## River

`VALUE → SIZE EXCLUSIONS → BLUFF ANCESTRY → HERO BLOCKERS → EVIDENCE`

# Usage rule

Do not try to recall all cues in every hand. Use the cue tied to the current uncertainty.

Before a session select only:

- one fragile cue;
- one high-frequency cue.
