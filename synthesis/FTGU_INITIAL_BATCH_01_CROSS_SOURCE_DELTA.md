## Orthogonal foundational evidence

### Equity versus EV

E01 establishes a prerequisite mechanism:

`current equity → modified by price, realisation, future decisions and implied odds → estimated EV`

This should become a learning prerequisite, not necessarily a separate final table heuristic.

### Learning governance

E30 independently supports:

- prerequisite ordering;
- prediction before feedback;
- non-results-oriented review;
- concept coherence;
- balancing play, study and recovery.

This strengthens the repository learning system but does not alter table strategy.
