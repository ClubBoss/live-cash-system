## CI-C01 — Filter density classification

Two river ranges begin equally wide preflop.

- Range A checks flop and checks turn before betting river.
- Range B calls a flop bet, calls a turn bet and then raises river.

Question:

Which range is more likely to retain broad natural air, and what must be checked before using that conclusion?

### Answer key

Range A is structurally more likely to remain air-rich because it reached river with less voluntary filtering. Range B has filtered repeatedly and is more likely to be value-concentrated.

Still check:

- starting-range width;
- board/runout;
- sizing;
- whether value also checked through;
- opponent-specific evidence.

Mapped candidates: `H-W01-009`, `H-R05-001`, `H-W03-005`.

Mapped questions: `SQ-RIV-02`, `SQ-EXP-01`.

## CI-C02 — Origin range before blockers

The same bet-check-bet river line occurs once after BTN opened and once after UTG opened.

Hero holds the same bluff-catcher and blocker in both hands.

Question:

Should the blocker produce the same calling decision?

### Answer key

No.

BTN begins with more offsuit and weak combinations, so the line may preserve more bluff supply. UTG begins tighter and may arrive with less air. Reconstruct origin range and filtering before blocker refinement.

Mapped candidates: `H-W01-007`, `H-W01-009`, `H-W03-011`.

## CI-C03 — Bet-check-bet river audit

Villain c-bets a wide flop, checks turn and bets river. Hero beats all missed overcards but loses to every value bet.

Question:

What five steps precede the call/fold decision?

### Answer key

```text
1. origin range width
2. which value checked turn
3. which missed hands reached river
4. what the river size requires
5. blockers and player evidence
```

Do not call merely because the line is described as overbluffed in a course.

Mapped candidates: `H-W02-009`, `H-W03-005`, `H-W03-011`.

## CI-C04 — Triple-barrel bluff gate

Hero is the 3-bettor and arrives at river with a missed draw after betting flop and turn. The pool is suspected of overfolding this node.

Question:

What must be true before the river bluff is authorised?

### Answer key

- the preflop and flop/turn line plausibly contains the bluff;
- the turn size leaves enough marginal bluff-catchers;
- the river does not strongly repair Villain;
- credible value uses the same line and size;
- overfold evidence belongs to this exact configuration;
- adaptation and visibility are considered.

Mapped candidates: `H-W02-002`, `H-W03-001`, `H-W03-005`.

## CI-C05 — Protected check-back versus turn probe

Hero can c-bet a medium-strength made hand in position but checks back. Villain probes turn.

Compare two Villains:

- A probes only strong value and high-equity draws;
- B probes many weak pairs, single-card draws and air.

Question:

How should Hero's response differ?

### Answer key

Against A, continue selectively and respect the polar/strong probe. Against B, call more showdown value and raise more value/semi-bluff candidates because the branch is too merged and weak.

The initial check-back is defensible only if Hero retains enough resilient hands.

Mapped candidates: `H-W02-006`, `H-R04-010`, `H-R05-002`, `H-W02-007`.

This is a direct drill for `H-W02-006` and `H-R04-010`.

## CI-C06 — Float-bet response by hand function

Hero is OOP preflop raiser and checks a protected flop range. Villain stabs too wide.

Hero has:

- Hand A: low showdown value with useful backdoors;
- Hand B: medium showdown value that beats many stabs;
- Hand C: strong low-urgency value.

Question:

Must all three exploit through check-raise?

### Answer key

No.

- A may check-raise as bluff/semi-bluff.
- B often calls to preserve Villain's weak range.
- C may call or raise depending on protection and value retained by Villain.

A range-level error creates hand-specific responses.

Mapped candidates: `H-W02-004`, `H-W02-005`, `H-R05-002`, `H-R04-010`.

## CI-C07 — Small river probe elasticity

Hero is OOP on river after Villain bet flop and checked turn. Hero can bluff for 25% pot or 75% pot. Assume Villain folds the same ace-highs and weak pairs to both sizes.

Question:

Which size may exploit the response error more efficiently, and what can still make it wrong?

### Answer key

The smaller size may be more efficient because it risks less while Villain should theoretically defend wider. It can still be wrong if:

- Hero lacks enough value for the small merged range;
- the river does not favour Hero;
- Villain's check-back range is stronger than assumed;
- Villain raises enough;
- larger sizing targets a different value/fold region more profitably.

Mapped candidates: `H-W02-001`, `H-W02-003`, `H-W03-006`.

## CI-C08 — Click-back branch split in a 3-bet pot

OOP 3-bettor c-bets too wide and overfolds to a small IP raise, but when OOP flop three-bets, the range is strongly value-heavy.

Question:

Is “Villain is weak” a valid summary?

### Answer key

No.

Correct split:

```text
c-bet/fold branch → attack more
c-bet/three-bet branch → continue tighter
```

Raise expansion and raise-fold discipline can coexist.

Mapped candidates: `H-W02-004`, `H-W02-005`, `H-W03-004`, `H-W03-006`, `H-W02-007`.

## CI-C09 — Filtered underbluff fold

Villain entered from a tight position, called a flop raise, called a turn bet and jams river. Hero holds a visually attractive blocker but cannot identify natural bluffs that take the line.

Question:

What is the default advanced response?

### Answer key

Fold toward baseline exploitatively unless branch evidence supports enough bluffs.

The blocker cannot create missing bluff families. Count credible value and air first, then compare with the price.

Mapped candidates: `H-W02-008`, `H-W02-009`, `H-W03-005`, `H-W03-011`.

This is a direct drill for `H-W02-008`.

## CI-C10 — Evidence, adaptation and live tell

A player folds twice to small flop raises and appears uncomfortable. Later the same player calls weak pairs and uses a bluff three-bet.

Question:

How should exploit confidence evolve?

### Answer key

- The first two folds are suggestive, not proof.
- The later calls and bluff three-bet are falsifiers.
- Reduce the exploit and return toward baseline.
- The visible discomfort is evidence with low weight, not a range conclusion.

Mapped candidates: `H-W02-007`, `H-R04-008`.

This is a direct drill for `H-R04-008`.
