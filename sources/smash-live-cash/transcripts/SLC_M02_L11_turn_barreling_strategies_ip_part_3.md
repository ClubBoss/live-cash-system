## [15:10] When a flush draw is a good or bad river bluff

A missed flush draw is not automatically unusable. Its quality depends on which flush draws remain in OOP's calling range.

- If OOP retained nut-flush draws, low flush-draw blockers can remove folds and become poor bluffs.
- If those lower flush draws were already removed from OOP's range, some higher club blockers may become viable.

The source's general instruction is to compare the exact cards with the opponent's check-call range rather than apply a blanket rule.

## [16:40] Narrow value means narrow bluffs

When the line represents very few value combinations in a 200–400bb pot, Hero must resist bluffing simply because a large amount is already invested. A candidate with poor removal should be abandoned rather than forced into the range.

The defender should rank bluff-catchers through value-blocking and bluff-unblocking. The aggressor should arrive with the required earlier-street bluffs, use the correct candidates and accept that a sound bluff may lose in one instance while improving long-run value realisation and table image.
