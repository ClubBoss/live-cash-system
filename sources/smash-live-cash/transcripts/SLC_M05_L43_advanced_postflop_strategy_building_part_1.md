# Detailed Source-Faithful Record

## Build the actual game

Nick and Brad establish a process for solving the games Brad plays: correct rake or no-rake structure, effective stack, realistic preflop ranges and a limited set of actionable sizes.

The tree can include small, medium and large later-street sizes and more than one raise size when a branch needs it. Complexity is justified only when it reveals a distinct hand class or meaningful EV difference.

## Aggregate reports before individual hands

Large board reports and spreadsheets expose global check, c-bet and sizing patterns. The student should predict first, review the aggregate result and then open the most surprising boards.

Some low or dynamic boards lose far more EV from the wrong size than from a small frequency error. When nearby sizes are used by the same classes for nearly equal EV, one practical size can replace them.

## Protected passive branches

Strong or connected hands sometimes check because future turns can build the pot, call overbets or protect the checking range. Slowplay is less useful when future streets cannot naturally put money in.

Before betting a broadway hand, ask whether it folds better hands or merely folds hands already dominated.
