# Source-Faithful Record

A range is capped when a prior action is inconsistent with the strongest hands and no later card has restored those hands to meaningful frequency. Being capped is not itself a theoretical error; failing to defend the capped branch adequately is.

The balanced plan can split sizes: overbets with strongest value and suitable bluffs, modest bets with thinner value/protection, and checks with showdown-value hands lacking a profitable betting function. Against an opponent who massively overfolds the capped branch, the exploit may become deliberately unbalanced: overbet many bluffs and semi-bluffs while using smaller sizes for value that would otherwise receive no action.

# Explicit Instructor Mechanisms

- Declare a range capped only from action history plus the current card.
- A capped range can be theoretically sound if defended appropriately.
- Use large polar bets when one range holds unique strong hands.
- Use smaller value/protection bets when a large size would fold all worse hands.
- Against severe capped-range overfolding, bluff large more often and value bet smaller.
- Do not turn medium showdown value into a bluff without a clear range-removal reason.
