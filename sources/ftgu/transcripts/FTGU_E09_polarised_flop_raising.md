# Detailed Source-Faithful Record

## When a raising range is required

The lesson contrasts call-only nodes with flops where immediate aggression matters. A raising range becomes more attractive when:

- strong hands are vulnerable to many turn cards;
- value can be extracted now from draws and made hands;
- the defender is out of position and cannot control later streets;
- the board creates urgent equity denial;
- the bettor's continuing range can support a large value/bluff split.

## Polar construction

A polar raise contains:

- very strong value that remains in good shape after the bettor continues;
- bluffs or semi-bluffs with low showdown value, strong improvement potential, nut potential or useful future-barrel properties.

Peter explicitly rejects the shortcut "I probably have the best hand, therefore I can raise for value." Value raising depends on the hand's equity against the range that continues, not against the full betting range.

## Match the response to the betting range

Against a polar betting range, medium-strength raises tend to fold out bluffs and get action from stronger hands. The preferred response is therefore also more polar. Against a merged betting range, later lessons allow a more merged response.

## Sizing and exploit

Polar raises generally use a meaningful size rather than a small token raise because the branch represents strong value and high-quality bluffs. Against an opponent likely to overfold later, additional exploitative barrels can be added, but that imbalance is explicitly opponent-specific.

# Explicit Instructor Mechanisms

- Build a raising range when protection, position and immediate value create urgency.
- Value raises must perform well against the continuing range.
- Polar raises pair nutted value with bluffs that have low showdown value and strong future properties.
- Respond more polar to a polar betting range.
- Use a substantial size when the raise branch is strongly polar.
- Extra bluff volume requires an explicit overfolding assumption.
