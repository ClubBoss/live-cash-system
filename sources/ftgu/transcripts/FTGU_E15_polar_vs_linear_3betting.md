# Source-Faithful Record

The lesson presents polar and linear three-betting as responses to fold equity, calling-range availability and opponent type rather than fixed hand charts.

A polar range contains strong value plus weaker hands that prefer a fold and are not attractive calls. It is favoured when the three-bet generates substantial fold equity and a profitable calling range can remain between value and bluffs. A linear range takes the strongest available hands in descending order and is favoured when fold equity is low, the opponent continues too much, or the defender does not want a separate flatting range.

The source links larger sizing more naturally to polar ranges that contain strong value and bluffs seeking pressure, while a more linear isolation range can often use a smaller size. Position, rake and opponent continuation tendencies change both the range shape and the width.

# Explicit Instructor Mechanisms

- Choose polar versus linear by expected folds and whether a calling range exists.
- Polar bluffs should gain materially from folds and retain useful blockers/equity.
- Linear three-betting concentrates on hands that perform best when called.
- Low fold equity pushes strategy toward linear value/isolation.
- High fold equity plus a viable calling range supports polarization.
- Sizing and range shape should agree rather than be selected independently.
