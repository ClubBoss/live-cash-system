## Carrot Grade 1 completion delta

Lecture 10 closes the Grade 1 lecture sequence and adds one important ordering boundary:

```text
ACTION CATEGORY
→ RANGE / TEXTURE / EV
→ TARGET RESPONSE
→ BLOCKER AS FINAL SELECTOR
→ EXPLOIT EVIDENCE
```

Strongest additions:

- blocker limitation rule;
- insufficient-reason trap;
- turn-to-river blocker reversal;
- dead-suit and backdoor-flush raise patterns;
- completed-flush blockers for bluff, thin value and bluff-catching;
- value blockers in polar river bluff-raises;
- active-recall and anti-spoon-feeding study process.

The main strategic value is not a new rule count. It is protection against a common misuse: allowing one blocker to create an action that range and EV do not support.
