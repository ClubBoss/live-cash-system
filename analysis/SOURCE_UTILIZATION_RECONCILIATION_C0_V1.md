## Purpose

Close residual positive-net-EV value in the repository source corpus after A0–A11 and B0–B7 without reopening the curriculum into one lesson per source item.

The governing question is not `is this P0/P1?` but:

> Does the learner-facing value of materializing this source mechanism exceed implementation cost, strategy-risk, cognitive load and maintenance cost?

Every admitted source family receives an explicit disposition:

- `CORE_TRAINED` — scored learner treatment exists;
- `SUPPORTING` — the source strengthens an already-trained mechanism and does not justify a duplicate skill;
- `REFERENCE` — useful baseline/context, but not a scored exact answer-key;
- `FIELD_GATED` — mechanism may be trained, population magnitude is not admitted as universal truth;
- `VISUAL_AUTHORITY_PENDING` — exact hand/frequency/colour claims require targeted chart/video review;
- `PLAYER_DEVELOPMENT` — pedagogy/workflow, not poker strategy;
- `SOURCE_ACCESS_REQUIRED` — positive-EV skill remains fail-closed because inspectable authority is insufficient;
- `LOW_EV_EXCLUDED` — cost/risk exceeds expected learner value.
