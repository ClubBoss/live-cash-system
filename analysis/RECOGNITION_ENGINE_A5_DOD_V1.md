# A5 — Board / Hand / Range Recognition Engine — 10/10 DoD V1

Status: `ACTIVE_WITH_PARTIAL_DRAW_TAXONOMY`

## Mission

Make recognition fast, contextual and transferable: the learner should notice the decision-relevant signal before trying to remember a line.

## 10/10 definition

A5 is 10/10 for source-supported scope when:

1. Board recognition is `board × arriving ranges`, never a texture nickname alone.
2. Runout recognition includes action ancestry: blank/game-changing labels cannot ignore what strong hands left or remained in the branch.
3. Concrete combos bridge to reusable hand family + decision-relevant traits.
4. Relative hand strength is contextual, not an absolute pair-category score.
5. At least two recognition stimuli, three direct decisions, two transfer stimuli and one boundary exist for supported core families.
6. Recognition prompts are short enough to become perceptual cues rather than essays.
7. The learner sees contrast pairs: same board/different ranges; same ranges/different board; same family/different vulnerability; same action ancestry/different turn.
8. A board label never directly implies an action without range/context.
9. A hand-family label is an intermediate representation, not mastery or the final action.
10. Non-identical stimuli are required before transfer claims.
11. Source-limited draw taxonomy is not expanded beyond explicit authority.
12. `W4-DRAW-01` remains PARTIAL until an admitted source supports the intended taxonomy and boundaries.
13. Trigger-bound memory hooks exist for board ownership, runout shifts and combo→family→traits.
14. Scaffolding can fade to hidden-cue recognition.
15. Remaining gaps are source ingestion or diminishing-return volume.

## Source boundary

FTGU E07/E08/E20/E21 plus admitted integrity authorities strongly support board/range, runout and relative-strength mechanisms. FTGU E01/E09 support draw equity/quality and raising properties, but the proposed full `nut/weak/combo/pair+draw` taxonomy is broader than the current audited authority.

Do not fabricate a complete draw taxonomy merely to satisfy symmetry with other recognition families.

Executable validation remains pending while local execution is unavailable. GitHub Actions are not a development gate.
