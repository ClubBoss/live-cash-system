# Practical Mastery — Wave 0 Skill Graph V1

Status: `W0_DOD_STATIC_PASS / EXECUTABLE_TEST_NOT_APPLICABLE`

## Purpose

Define the live-cash NLHE skill topology that replaces the legacy assumption that eleven LCMs are the complete curriculum.

Legacy LCMs remain conceptual authorities where source-supported. They no longer define the number of learning modules or the amount of required practice.

## Skill graph domains

### A. Foundation / calculation
1. Pot odds and required equity
2. Raw vs realised equity
3. Implied and reverse implied odds
4. Outs quality: clean / dirty / dominated
5. Combo counting and removal
6. SPR and effective-stack calculation
7. Value/bluff break-even intuition

### B. Preflop
1. RFI by position
2. Limp / overlimp / isolation
3. Calling IP
4. Calling from BB
5. SB versus opens
6. Linear/polar/merged 3-betting
7. Facing 3-bets
8. 4-bet fundamentals
9. Squeezing
10. Depth / rake / live-size adjustments

### C. Blind play
1. BB vs UTG/HJ/CO/BTN opens
2. BB vs open-size changes
3. SB vs opens
4. SB first-in raise/limp/fold structure
5. BB vs SB raise
6. BB vs SB limp
7. SB response after BB aggression
8. BvB SRP postflop
9. BvB 3-bet-pot postflop

### D. Board and hand recognition
1. Major flop classes
2. Turn-card classes
3. River-card classes
4. Made-hand families
5. Draw families
6. Relative hand strength
7. Vulnerability
8. Nut / range / equity shifts

### E. SRP OOP
1. Range checking
2. Check-call / check-fold
3. Check-raise
4. Small-cbet defence
5. Large-cbet defence
6. Leads / donks
7. Delayed aggression
8. Turn leads
9. River block / bluff catch
10. Realisation under high SPR

### F. SRP IP
1. Range c-bet vs selective c-bet
2. Small / large c-bet
3. Check-back
4. Delayed c-bet
5. Float/stab
6. Turn barreling
7. Capped-range attacks
8. Overbets
9. Thin value
10. River pressure

### G. 3-bet pots
Four role matrices: aggressor IP, aggressor OOP, caller IP, caller OOP. Each must cover major board classes, flop sizing/check branches, turn continuation and river/stack-off decisions.

### H. 4-bet / low-SPR pots
1. Preflop 4-bet families
2. Flop compression
3. Relative polarisation
4. Small-bet / check branches
5. AK / QQ / JJ / blocker-hand families
6. Jam exposure
7. Protected checks
8. Turn/river low-SPR planning

### I. Turn mastery
Blank, overcard, draw-completing, paired and range-changing turns; barrel, probe, lead, delayed c-bet, check-raise, thin value, pot control and river setup.

### J. River mastery
Value target, thin value, bet/fold, bet/call, bluff selection, missed-draw bluffs, blocker/unblocker logic, bluff catching, block bets, probes, overbets/jams and population deviations.

### K. Multiway / limp-heavy live
Relative position, closing action, value thresholds, bluff suppression, draw quality, overcalls, family pots, isolation, overlimps, large live sizing and multiway river value.

### L. Deep / straddle / live geometry
100/150/200bb plus selected 300bb+ nodes; one-pair devaluation, nut-potential premium, reverse implied odds, leverage, stack-off thresholds, straddle position/action order and SPR compression.

### M. Exploitative live cash
Player evidence, branch-specific population hypotheses, thin-value expansion, bluff suppression/expansion, exploit folds/calls, sizing exploits, limp-heavy exploits, timing/sizing evidence discipline, table/seat/game selection and read updating.

### N. Integrated execution
Topic-hidden mixed decisions, timed recognition, changed-node transfer, boundary cases, mistake-family repair, delayed retrieval, real-hand routing and full-player gauntlets.
