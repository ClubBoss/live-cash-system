# B5 — Automaticity & Memory Fading — 10/10 DoD V1

Status: `ACTIVE`

## Mission

Make useful scaffolding temporary. The learner should progress from explicit mechanism cues to self-extracted table signals without memorizing or reciting a permanent checklist.

## 10/10 definition

1. Unseen concepts are never hidden-cue tested.
2. Newly taught skills can receive guided/reduced perceptual cues.
3. Successful distinct recognition moves support toward reduced/hidden cues.
4. Successful changed-node transfer is required before stable hidden-cue practice is preferred.
5. A recent wrong answer restores support rather than repeatedly blind-testing the same failure.
6. High-confidence wrongs restore more support than low-confidence misses.
7. Scaffolding is derived from learner evidence, not only hard-coded per card.
8. Guided cues point to an event/signal family; they do not prescribe a long ordered checklist.
9. Hidden mode does not reveal skill/topic/correct variable before commitment.
10. Correct hidden-cue performance remains ordinary Practical Mastery evidence.
11. The same fading policy can be used by perceptual practice and later adaptive scheduling.
12. Repeated success on the same exact stimulus is insufficient for full fading; distinct successful IDs matter.
13. Boundary/generalization failures can restore reduced guidance even when direct decisions are strong.
14. Fading has no new progress schema requirement unless a material need appears.
15. Further sophistication stops when it would add state complexity without evidence of improved real-table transfer.
