# A8 — Turn + River Decision Engine — 10/10 DoD V1

Status: `ACTIVE`

## Mission

Train later streets through ancestry, surviving ranges, runout shifts, price and blockers — not through street-label slogans.

## Canonical mastery families

Turn: `TURN-01..05`.
River: `RIV-01..05`.

Legacy SRP later-street IDs remain stable but become reinforcing bridges:
- `OOP-06 -> TURN-04`
- `OOP-07 -> RIV-03 / RIV-04`
- `IP-03 -> TURN-02`
- `IP-04 -> TURN-03`
- `IP-05 -> TURN-02 / RIV-01 / RIV-02` depending branch
- `IP-06 -> TURN-05 / RIV-01`

They must not force the learner to prove the same concept twice.

## 10/10 definition

1. Each canonical TURN/RIV family has recognition, direct decision, changed-node transfer and a boundary.
2. Every turn decision identifies the prior flop branch before using a runout heuristic.
3. Blank/scare/completing/paired/range-shifting are contextual classes, not action labels.
4. Barreling requires a value/bluff reason and surviving range logic, not "scary card" alone.
5. Probing requires a genuinely weakened/capped checked-back branch and must be reassessed when the turn recreates strength.
6. Turn leads remain source-scoped rather than becoming donk-bet autopilot.
7. Pot-control/thin-value choices state the worse hands that can continue or the showdown value being preserved.
8. River value requires naming plausible worse calls for the chosen sizing.
9. River bluffs require low showdown value plus blocker/unblocker/line-ancestry support where source-relevant.
10. Bluff-catching combines price with credible bluff supply; pot odds alone do not manufacture bluffs.
11. Block bets/probes are a branch tool, not a universal cheap-showdown button.
12. Underbluff/overbluff exploits remain evidence- and branch-qualified.
13. Exact solver frequencies are not invented.
14. Correct-option positions are not structurally fixed.
15. Duplicate legacy SRP later-street skills are linked rather than separately re-mastered.
16. A8 closes only after adversarial review finds no material later-street mechanism gap beyond source/executable limits.
