# B6 — Adaptive Player Engine V2 — 10/10 DoD V1

Status: `ACTIVE`

## Mission

Repair the causal failure mode rather than merely repeating the same topic. The scheduler must distinguish recognition, mechanism/reasoning, transfer, boundary/generalization and automaticity/latency needs.

## 10/10 definition

1. Wrong recognition items route to recognition/perceptual repair before harder transfer items.
2. Correct action + wrong reason is classified as mechanism/reasoning failure.
3. Wrong changed/mixed items are classified as transfer failures.
4. Wrong boundary items are classified as overgeneralization/boundary failures.
5. Correct but materially slow responses can create an automaticity need when timing data exists.
6. High-confidence wrongs retain elevated priority.
7. Repaired latest attempts remove the prior debt; historical misses do not live forever.
8. Intensive skills receive an underexposure bonus until their EV-weighted rep-depth target is approached.
9. Perceptual table-state items are preferred for recognition/automaticity repair when available.
10. Mechanism failures can return to direct/action+reason reps rather than blindly adding more table noise.
11. Transfer failures prefer non-identical changed/mixed stimuli.
12. Boundary failures prefer boundary stimuli.
13. No unseen concept is scheduled as adaptive repair.
14. The engine remains bounded and avoids overfitting one noisy miss.
15. Additional learner-state fields are optional/backward-compatible unless a hard truthfulness need requires a schema bump.
