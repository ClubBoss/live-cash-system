# A1 — Mental Compression / Memory System — 10/10 DoD V1

Status: `ACTIVE`

## Mission

Replace fragile learner-facing checklist memorisation with trigger-bound habits, compressed heuristics, contrast learning and one-variable transfer.

The target is not that a learner can recite a sequence in the app. The target is that relevant table signals automatically call the right model to mind.

## 10/10 definition

A1 is 10/10 only if:

1. Existing long checklists/sequences are classified as `TRUE_SEQUENCE`, `TRIGGER_RULE`, or `ENVIRONMENTAL_HABIT`.
2. `TRUE_SEQUENCE` is rare and limited to actions that genuinely must occur in order.
3. Table-preparation work (stack scan, straddle, unusual seat/action structure) is moved out of the decision moment where possible.
4. Every high-EV learner heuristic has: Trigger, Default, Why, Amplifiers, Reversals/Boundary, Examples/Transfer cue.
5. Heuristics are causal compressions, not unsupported slogans.
6. No heuristic uses `always/never` unless the source truly supports an invariant.
7. Contrast pairs are available for structurally confusable nodes (BB vs SB, small vs large open, IP vs OOP, HU vs multiway, shallow vs deep).
8. One-variable transformations are a first-class practice mechanism.
9. Prediction-before-explanation is supported as a learner mode.
10. Scaffolding can fade: learner does not need to recite category labels forever.
11. Solver/chart evidence may feed heuristics; exact mixes/cells are not exposed as universal memory obligations.
12. Every rule states a boundary or reversal condition when one exists.
13. The memory layer points back to source refs and skill IDs.
14. The runtime can retrieve relevant rules by skill and trigger family.
15. Remaining gaps after gauntlet are empirical wording/UX questions or source-blocked strategy questions.

## Sequence decomposition policy

### TRUE_SEQUENCE
Use only when ordering itself is the skill. Example: a short procedural pre-hand setup where later steps depend on earlier observations.

### TRIGGER_RULE
Use when a table cue should activate a model immediately. Example: `large open → fringe BB calls lose EV first`.

### ENVIRONMENTAL_HABIT
Use when the observation is better collected before decision pressure. Example: `scan effective stacks / straddle before the hand`.

## Compression unit

A learner-facing Practical Rule must contain:

- `trigger`: what should catch attention;
- `default`: directional action/model;
- `why`: causal mechanism;
- `amplifiers`: variables that strengthen the default;
- `reversals`: variables that weaken or flip it;
- `transferCue`: one variable to change in practice;
- `sourceRefs` and `skillIds`.

## Memory doctrine

Do not teach: `remember seven checks in this order` when the same competence can be decomposed into table habits + event-triggered rules.

Prefer:

`notice → interpret → act → vary → retrieve later`.

## Hard stops

- unsupported strategy answer key;
- memory simplification that changes strategy semantics;
- compression that hides a material boundary;
- architecture conflict with evidence integrity.
