## Mission

Propagate live-cash variables back into canonical decision families so deep stacks, straddles, large opens, limpers, multiway pressure and asymmetric stacks are not learned only inside a separate "live" chapter.

## 10/10 definition

1. Live context reuses canonical skill IDs; no parallel live-only mastery graph.
2. High-value preflop skills are exposed to large live opens, limpers, straddles, depth and asymmetric effective stacks.
3. Core postflop skills receive selected deep/multiway/SPR transformations when the mechanism truly changes.
4. River value/bluff-catch skills receive live range/evidence variation without turning population hypotheses into universal laws.
5. 100bb heads-up defaults remain the baseline only where assumptions match.
6. Straddle changes forced unit/action order/working depth before strategy is applied.
7. Deep transformations emphasize position, nut potential, reverse implied odds and future leverage rather than blanket "play tighter" slogans.
8. Multiway transformations account for ranges behind and stronger aggregate continuing regions.
9. Large live sizes change price/range selection and are not treated as ordinary online sizes.
10. Asymmetric physical stacks are reduced to pairwise effective depth for the actual branch.
11. Exploit changes require observed branch evidence.
12. No exact live-population frequency is fabricated.
13. Each added rep changes a named material live variable.
14. Additional live variants stop once new reps mostly restate existing causal transformations.
15. Remaining rare casino quirks are admitted only if positive net EV after maintenance/complexity cost.
