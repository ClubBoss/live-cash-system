# A2 — First Journey Vertical Slice — 10/10 DoD V1

Status: `ACTIVE`

## Mission

Build the first complete Practical Mastery learner journey before scaling the rest of the curriculum.

The slice must make the learner feel table-relevant progress quickly while preserving evidence integrity.

## 10/10 definition

A2 is 10/10 only if:

1. The journey is runnable as a distinct product route.
2. It follows A0 learning-route authority rather than W1→W14 chapter order.
3. It interleaves foundation, preflop, blind, board and first postflop capability.
4. It uses A1 trigger-bound rules instead of long checklist memorisation.
5. Each new mechanism begins with prediction or a concise causal explanation before scored evidence.
6. The learner reaches a concrete table decision early.
7. At least one one-variable changed-node transfer is part of the journey.
8. Topic labels/scaffolding fade by the end of the slice.
9. Recommendation is driven by the route engine and includes `whyNow`.
10. Source-blocked or corpus-incomplete skills fail closed instead of becoming fake mastery steps.
11. Progress uses Practical Mastery schema only; legacy module completion is not migrated.
12. Repeated one-card grinding cannot inflate evidence.
13. Wrong answers route to repair before nominal progression when material.
14. The experience exposes a compact reason for the action, not just right/wrong.
15. No production/default-route cutover occurs until the slice survives its own gauntlet.

## First-journey capability hypothesis

`FND-01 → FND-02 → PF-01 → PF-04 → W4-BOARD-01 → IP-01 → BL-04 → W4-RUNOUT-01`

This is deliberately spiral:
- basic EV/price;
- position and opening;
- BB identity;
- first board/range ownership;
- first postflop action;
- changed blind price;
- first runout shift.

The learner does not need full topic mastery before seeing why the concept matters at the table.

## Learner loop per step

`predict → rule/why → scored recognition/decision → changed node when available → route recommendation`

## Closure rule

A2 closes only when remaining improvements require actual learner observation or broader content production rather than obvious architecture/UX repairs.

Executable validation remains pending while local execution is unavailable. GitHub Actions are not a development gate for this program.
