# Batumi Preparation Plan

## Target

Two-week live-cash trip focused on 1/3 and 2/5 No-Limit Hold'em.

## Current player profile

- Primary background: live and online tournaments.
- Reported strength: generally successful tournament play.
- Transition risks: deep stacks, OOP play against frequent 3-bets, SB vs BB, and BB defence.
- Learning constraint: large chart sets are not a viable primary memory system.

## Preparation objective

Build a compact and executable system that improves decisions in the highest-frequency and highest-cost live-cash nodes before the trip.

## Priority sequence

1. Establish game conditions: rake, buy-in caps, straddles, match-the-stack, typical effective stacks.
2. Build BB defence anchors and adjustment rules.
3. Build SB vs BB architecture.
4. Build facing-3-bet and OOP continuation systems.
5. Build deep-stack one-pair and SPR discipline.
6. Cover 3-bet pots and multiway pots.
7. Add live population exploits only after the baseline is stable.
8. Train a one-page session card and post-session review loop.

## Deliverables before departure

- Master Playbook v1.
- One-page session card.
- BB and SB anchor ranges.
- Facing-3-bet decision tree.
- Deep-stack red-flag checklist.
- Player-type adaptation notes.
- Session log and hand-capture routine.
- Mixed assessment covering priority nodes.

## Field feedback loop

```text
Observe condition or hand
  -> record facts before interpretation
  -> compare with current playbook
  -> classify execution error / model gap / opponent-specific evidence
  -> update drill or contradiction ledger
  -> revise playbook only when evidence warrants it
```
